Project Title: Personal Portfolio Website

Description:
I developed a responsive Personal Portfolio Website using HTML, CSS, and JavaScript to showcase my profile, skills, projects, resume, and contact information. The website features a clean and modern design with smooth scrolling navigation, hover effects, and interactive sections. It includes a dedicated resume download option and a structured layout for better user experience. The project is fully responsive and works efficiently across different devices and screen sizes, providing a professional online presence.
